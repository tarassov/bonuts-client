# Bonuts TypeScript

## Types and naming

- Import types with `import type` whenever possible. If you touch code with incorrect type imports, fix them as part of the change.
- Type aliases start with `T`. Interfaces start with `I`. Enums do **not** start with `T`.
- Prefer enums over type aliases or string unions when the value set is fixed and named states improve readability.
- Boolean variables and props use explicit `is*` / `has*` / `can*` naming.
- Prefer precise types over `any`. No implicit `any`. Avoid weak typing unless there is a real integration constraint.
- When narrowing improves readability, prefer explicit guards.
- Prefer explicit return types for public functions.

## Where types live

- Define reusable types outside the component body.
- Move non-props component-local types out of the component body, and out of the component file when it reduces visual noise.
- Component props are the exception: keep props types/interfaces in the same file as the component.
- In FSD, define non-trivial types in the `model` segment when they are shared beyond one component.

## Generated API

- **Do not manually modify `src/services/api/bonuts-api.ts`.** It is autogenerated.
- Regenerate with `yarn generate-api` (uses `openapi-config.ts`).

## RTK Query cache tags

- Prefer helpers from `@/shared/lib/rtk` over manually constructed tag arrays or callbacks: `providesList`, `providesListTag`, `providesInfiniteList`, `providesNestedList`, `invalidatesList`, `invalidateId`, `cacheByIdArg`, `cacheByIdArgProperty`, `cacheByArgProperty`, `cacheByIdResultProperty`, `invalidatesUnauthorized`, `invalidatesUnknownErrors`, and the `cacher` object.
- Add a focused helper there when an endpoint response shape is not covered.
- Configure cache invalidation **in the RTK Query endpoint that changes the data**, not in a UI hook or component. UI code may invalidate tags directly only when no responsible mutation endpoint exists.

## State and forms

- Prefer RTK slices / RTK Query for server state. Do not duplicate server state in Redux.
- Forms use `react-hook-form`, validation with `yup` where applicable.

## Performance

- Reach for `React.memo` / `useMemo` / `useCallback` only for measured bottlenecks.
- Use `@tanstack/react-virtual` for large lists; RTK Query caching for server data.

## Verify

```bash
yarn typecheck   # tsc --noEmit
yarn lint        # typecheck + biome + fsd:check
```
